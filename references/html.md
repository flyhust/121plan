# 交互式执行看板交付

完整计划的默认最终交付为实际可用的交互式 HTML 文件／预览，无需用户再次指定。填入访谈与测算形成的真实计划，不只贴源码或给空模板。先检查已有成果，保留记录与字段；新业务单独建项目，避免共用存储键导致串数据。用户只需局部答疑或明确选择其他格式时，不强行生成页面。

## 视图

根据项目取舍，商业计划默认支持六个视图：
1. 目标总览：长期及三年愿景、本轮意义、目标口径、承诺与代价、起点、进度、情景及容量。
2. 十二周全景：全部十二周默认可见，可展开行动；用户要求全部 view 时不能只提供一周下拉选择器。
3. 今天执行与周时间表：高效周模板包含策略、缓冲、抽离时间块及其他重要活动；按正式开始日期和用户时区列到期／逾期／完成事项。
4. 内容／制作工作台：脚本、制作状态、原创与分发记录及结果。
5. 客户／事项跟进：阶段、下一步、到期时间，可筛选。
6. 周评分与复盘：关键策略项执行率、领先与落后指标、原始计划、调整记录；责任会议的伙伴、时间、成果汇报和反馈。无伙伴时明确标注替代复盘。周期总结含庆祝进步及可选第十三周补完记录。

没有对应业务的视图可换成项目里程碑与交付，不硬加销售功能。

任务支持勾选与撤销，按周查看执行评分，填写实际结果和复盘笔记。提供全部展开／收起、按状态筛选等必要操作。每日动作关联父策略，周评分按达到约定完成标准的策略项计算；子步骤不能重复计分。结果指标独立展示。页面说明保存位置与备份方式；不把静态页面内的规则提示包装成实时 AI 分析，深入复盘可将导出记录交回对话处理。

## 记录与恢复

结构化状态至少区分 schemaVersion、projectId、planVersion、timezone、startDate、vision、commitments、assumptions、goals、strategies、tasks、timeBlocks、results、reviews、accountabilityMeetings；商业项目另含 leads 和 payments。tasks 通过 strategyId 关联策略，策略记录每周频次与验收标准。所有可编辑项及 checkboxes 需持久保存。旧版数据缺少策略分组时保留原记录，显式映射后再应用新评分，不能无提示重算历史成绩。

本地版本用项目隔离的持久存储，捕获存储失败并提示。提供 JSON 导出和导入；导入先校验结构和版本，预览替换／合并范围，替换前备份，错误输入不破坏现有记录。显示最近保存状态。

本地存储仅在当前浏览器／来源有效，不宣称跨设备同步或由助手自动读取。导出文件和跟进名单可能包含业务信息；公开发布前不内置实际客户资料。

## 可用性与交付

- 移动端单列、易点击的复选框、清晰对比度、键盘可操作、输入字段有标签。打印时展开必要内容。
- 金额和日期有明确单位，空数据不显示虚假零值或成功率，表单限制非法数值。
- 动态显示用户文本时采用安全文本渲染，避免将导入内容当作可执行 HTML。
- 验证：十二周齐全；勾选后刷新保留；切换周次评分正确；未来／逾期任务分母正确；一项策略拆成多个子记录不会增加主评分权重；未达到频次不计完整策略；首周无上周分数不显示零分；周时间块可查看及编辑；导出导入往返成功；错误导入不覆盖；移动端布局可读。
- 用实际可用浏览器或测试工具检查。工具不可用时明确未完成哪些交互验证，不能只查文件存在就声称页面可用。
- 提供实际文件链接或已验证预览。手机上的本地附件可能只显示源码，电脑本地服务地址不等于手机可访问网址。
- 如用户报告 Unable to load file，定位路径、预览方式和设备问题；仅改文件名不代表修复。使用可用预览或提供具体的浏览器打开方式；涉及公开部署时核实用户授权。无法提供跨设备入口时明确说明限制，不声称已解决。

技能指导建立这些能力，不代表仅安装技能就已具备网站、同步后端、提醒或发布服务。
