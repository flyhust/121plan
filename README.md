# 121plan · 十二周计划与执行教练

把新机会、业务目标或工作项目，整理成可执行的十二周计划，并由 AI 助手生成互动式 HTML 执行看板。

## 如何工作

1. **分轮访谈**：先了解愿景、起点、目标、资源与限制，每轮只问几个关键问题。
2. **建立计划**：连接长期与三年愿景，明确十二周目标、关键策略、承诺与代价。
3. **安排时间**：建立包含策略、缓冲、抽离时间块的高效周模板。
4. **执行与反馈**：每日记录，按周评分，并安排每周责任会议；区分执行不足与策略问题。
5. **交付互动 HTML**：完整计划形成后，默认生成可查看全部十二周、勾选任务、记录结果及复盘的看板。

商业项目还可包含销售漏斗、内容拍摄安排、客户跟进、广告情景与交付产能测算。没有真实数据时明确标注假设，不编造转化率或承诺收入。

## 安装

这是 Codex skill，仓库根目录就是技能目录。需要支持本地 skills 的 Codex 环境；生成和检查 HTML 需要相应文件及浏览器工具。

将本仓库放到默认技能目录的 `121plan` 文件夹中。若设置了 `CODEX_HOME`，使用该目录下的 `skills/121plan`。

Windows PowerShell：

```powershell
git clone https://github.com/flyhust/121plan.git "$env:USERPROFILE\.codex\skills\121plan"
```

macOS / Linux：

```bash
git clone https://github.com/flyhust/121plan.git "${CODEX_HOME:-$HOME/.codex}/skills/121plan"
```

如果目标目录已经存在，不要覆盖已有文件；已有 Git 安装可在目录中更新。安装后重新打开 Codex 或开启新会话，让技能被发现。

## 开始使用

在 Codex 中输入：

> 用 $121plan 帮我规划一个新机会。先和我确认情况，最后整理成可互动的 HTML。

也可以继续已有计划：

> 用 $121plan 根据这份计划和本周记录，帮我评分、复盘，并更新下周安排。

提供现有计划文件或导出记录，助手才能依据实际进度继续。安装技能不会自动读取其他设备的数据。

## HTML 执行看板

技能要求按实际项目生成六类视图：

| 视图 | 内容 |
|---|---|
| 目标总览 | 愿景、目标、承诺、进度与资源 |
| 十二周全景 | 全部周计划、策略与可勾选动作 |
| 今天执行与周时间表 | 到期事项、高效周模板、三类时间块 |
| 内容／制作工作台 | 脚本、制作状态与发布记录 |
| 客户／事项跟进 | 阶段、下一步、到期时间 |
| 周评分与复盘 | 策略完成率、结果指标、责任会议与调整记录 |

支持保存、导出及导入备份。默认本地存储只在当前浏览器中有效，不自动跨设备同步。此仓库提供技能指令，**不包含已经部署的网站、生成器程序或同步后端**；具体 HTML 由助手结合用户计划生成并验证。

## 评分口径

主评分按本周关键策略项计算：

**周执行率 = 达到完成标准的策略项数 ÷ 本周计划策略项数。**

例如，“本周发布三条视频”是一项策略。发布两条时可以记录 2/3 的动作进度，但该策略尚未完成。拆出更多子任务不会提高它在主评分中的权重。成交、到账和利润独立记录。

## 方法依据

以 Brian P. Moran 与 Michael Lennington 的《The 12 Week Year》（《12週做完一年工作》）为方法参考，已对照愿景、周计划、评分、时间块、承诺、责任会议及周期复盘。

这是独立的应用技能，不是作者官方产品。仓库不包含原书 PDF；章节定位见 [原书对照索引](references/book-alignment.md)。商业漏斗、广告测试、客户管理及 HTML 为应用扩展。十二周是执行周期，不保证在十二周赚到一年收入。
